## Independent native UTF-8 finite audit

[Exact source](../agents/agent40/utf8-native.cjs) (blob `0df140602140cf433d2089e920e7ac4aafe3d322`), same engines. A separate strict scalar parser and manually encoded scalar oracle tested every one of **1,112,064 Unicode scalar values**, both fatal decoder BOM behaviors, zero mismatches on each engine. The byte corpus includes empty, every one-byte and two-byte sequence, and 100,000 three-byte + 100,000 four-byte sequences generated by xorshift32 seed `0x6a09e667`. **265,793** byte sequences, **43,353 valid**, **222,440 invalid**. Each engine agreed with the independent strict scalar parser on fatal success/value or invalid TypeError **name**. Do not infer parity of invalid TypeError messages.

All **265,793 nonfatal replacement strings** matched exactly, not only a hash. Python compact ensure_ascii JSON array SHA256 on each engine: `506cd6694714ae6ecd81399a0caff40f7a0c61e85b97f7876885706dfc6d29a5`. Initial browser extraction via Playwright inner_text collapsed double spaces and falsely suggested 10 mismatches; rerunning using **text_content** removed all ten. The corrected raw-text comparison is the result.

This motivates a bounded future wellformed-literal-byte proof for fatal non-ASCII inputs, but does not establish arbitrary streaming, ambient mutation, source admission, or runtime 2.5x compliance. Such yield broadening requires separate compiler validation.
