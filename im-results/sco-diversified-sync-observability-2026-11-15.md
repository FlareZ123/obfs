## Research question

The earlier [stateful step-only SCO study](sco-synchronizing-oracle-2026-11-15.md) searched for a short synchronizing input sequence using repeated runs of input symbol 1 before each probe. Its [falsification report](sco-sync-search-falsification-2026-11-15.md) found that **156/189** returned candidates did not physically merge all four hidden states in a 250-machine seeded corpus. That metric is useful, but it conflates physical state convergence with a weaker condition sufficient for functional output prediction: *observational equivalence*.

For a four-state deterministic binary Mealy machine, two states are observationally equivalent if every future binary input string produces identical output traces. Testing suffixes of lengths 1 through 3 suffices to distinguish inequivalent states for this finite-state bound. All classification happens in the evaluator **after** the public-query attack finishes; the attack does not inspect state IDs, transition tables, or output tables.

We report four separate predicates for an attacker-selected word: physical convergence over all four states, observational convergence over all four states, observational convergence over states reachable from the original hidden state 0, and observational convergence over states reachable from the private state **at the end of the discovery transcript**. The last predicate is relevant to an attacker continuing on the same nonresettable instance. It is distinct from behavior at the original unrepeatable initial state.

## Mechanism

The new `sims/sco-sync-diversified.js` remains a pure step-only chosen-input attack. It enumerates all 14 candidate binary words of lengths 1 to 3 in breadth-first order. For each candidate, it compares eight suffix traces of **exactly length 3**. It first performs two prefix-free probes of each suffix from the current hidden state, then twelve probes after cycling through binary **scramble sequences containing both symbols** of lengths 1 to 4. The scramble schedule is public and deterministic; the attacker has no private model data. Any output difference at suffix length 1 or 2 persists after extending that input to length 3, so shorter suffix checks are redundant for the four-state bound. This exact-depth restriction reduces the query cost while preserving the finite-state observational test.

This costs more chosen-input calls than the original restricted symbol-1 schedule. No defender code or SCO server authorization is weakened, and attack computation is outside the protected program's 2.5× runtime budget.

**Interpretation:** this is a deterministic 500-fixture empirical reduction in *post-discovery observable* false candidates. The attacker uses approximately 1.624× and 1.692× as many public oracle calls in the respective corpora. It does not guarantee a short global physically synchronizing word, and it makes no production-wide performance or anti-cloning claim.

A concrete limitation is a four-state permutation automaton with all-zero outputs: no nonempty word physically synchronizes it, yet all states are observationally equivalent, so a word is suitable for predicting its output behavior. Conversely, a public step API cannot reveal transitions of unreachable private states. More probing cannot certify their physical convergence.

## Black-box impossibility witness

The regression `unreachable private states make global physical synchronization undecidable` constructs two four-state machines with identical public step transcripts from their initial state 0. In the first, every state transitions to 0 on either input; any nonempty word physically synchronizes it. In the second, state 0 loops forever and the three other states form a closed 3-cycle on either input; no word can converge all four states. Both machines emit output 0 for every input from every state. Because the public initial state cannot leave 0, any adaptive black-box step-only attacker receives identical outputs under both models, regardless of query budget. The two global physical-sync answers differ. This is an exact indistinguishability argument for the stated public-access model, separate from the empirical 500-machine comparison.

## Limits and future adversarial tests

The tested state bound, alphabet, deterministic transition assumption, and four seeded distributions are narrow. A nonresettable public interface may irreversibly leave transient states during exploration. If the resulting state is later made resettable or a second initial instance is exposed, post-discovery observational convergence alone is insufficient. Additional distributions, adaptive distinguishing sequences, malicious state layout, longer alphabets, and real network transport remain open. A client with unlimited authorized access can also relay the server's behavior; this study addresses oracle learning rather than server code disclosure or unauthorized authentication bypass.

The result remains in `im-results/` and should not be promoted to a security guarantee.
