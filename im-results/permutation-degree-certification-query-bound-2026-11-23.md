# An exact black-box degree-certificate bound for arbitrary GF(2) permutations

**Agent 37, 23 November 2026. Intermediate mathematical derivation; independently check before promoting to \`results/\`.** This report relates to the bounded-degree *assumption* used by [the affine-triangular model inversion](two-sided-affine-bounded-anf-inversion-2026-11-23.md). It is a **lower bound on certifying that assumption** from black-box forward outputs under an unrestricted-permutation alternative, not a contradiction to the promised-degree inversion attack.

## Statement

Let \`n ≥ 3\`, \`1 ≤ D ≤ n−2\`, and grant an observer adaptive chosen-input access to a forward oracle \`F:{0,1}^n→{0,1}^n\`, with the **sole promise** that \`F\` is a permutation. The observer must decide without error whether *every output coordinate* has Boolean algebraic normal-form degree at most \`D\` (call this membership property \`LowDegree_D(F)\`). Neither source code nor a family representation is supplied.

**Theorem (deterministic exact worst-case query complexity).** The minimum worst-case number of **distinct** forward queries for a deterministic exact decider is exactly

\[
Q_\mathrm{cert}(n,D)=2^n-1.
\]

For \`n=32,D=1,2,3,4\`, this is **4,294,967,295** distinct forward outputs; the existing generic degree-two **529-query** interpolation is an *exact model only conditional on its degree promise*. No subexponential number of legitimate oracle observations can certify the promise against an arbitrary malicious higher-degree permutation in the worst case, even when the reference transcript was generated by the identity permutation.

## Lower-bound proof (mathematical)

Run an arbitrary deterministic adaptive certifier \`A\` on the identity permutation \`I(x)=x\`. Suppose it halts after at most \`q ≤ 2^n−2\` distinct oracle inputs. There must exist at least two different never-queried inputs \`u,v\`. Construct the transposition

\[
T_{u,v}(x) =
\begin{cases}
v,&x=u,\\
u,&x=v,\\
x,&\text{otherwise.}
\end{cases}
\]

It is a permutation. Since it agrees with \`I\` at every input in the reference transcript, the complete **adaptive** transcript on \`T_{u,v}\` is exactly the same: by induction, identical previous outputs imply that the deterministic policy chooses the same next input, which cannot be a hidden swap point. Therefore \`A\` must give the same verdict for \`I\` and \`T_{u,v}\`.

For a point \`s∈{0,1}^n\`, let \`δ_s(x)=1\` precisely when \`x=s\`. Over \`GF(2)\` its ANF is

\[
\delta_s(x)=\prod_{i:s_i=1}x_i\,\prod_{i:s_i=0}(1+x_i).
\]

The vector difference between the transposition and identity is the common scalar point-indicator difference

\[
T_{u,v}(x)\oplus I(x)
=(u\oplus v)\,(\delta_u(x)\oplus\delta_v(x)).
\]

The top-degree \`x_0 x_1 ··· x_{n−1}\` coefficient of \`δ_u⊕δ_v\` cancels (\`1⊕1=0\`). For each coordinate index \`j\`, the coefficient of the degree-\`n−1\` monomial \`∏_{i≠j}x_i\` is \`(1⊕u_j)⊕(1⊕v_j)=u_j⊕v_j\`, which is nonzero for at least one \`j\` because \`u≠v\`. Thus the scalar \`δ_u⊕δ_v\` has **degree exactly \`n−1\`**. At least one output coordinate is multiplied by its nonzero common vector coefficient \`(u⊕v)_k=1\`; this coordinate of \`T_{u,v}\` is its original linear identity bit plus a degree-\`n−1\` scalar. Since \`n−1≥2\`, there is no cancellation with the linear term, so \`degree(T_{u,v})=n−1\`.

Identity \`I\` has degree one, so it satisfies \`LowDegree_D\` for every \`D≥1\`, whereas \`T_{u,v}\` violates \`LowDegree_D\` because \`D≤n−2\`. Their adaptive transcripts are identical; any decider accepting the identity must falsely accept the transposition, contradiction. Hence any exact deterministic certifier must make at least \`2^n−1\` distinct queries in the worst case.

## Matching upper bound

Query the oracle on all inputs except one \`z\`. By permutation injectivity and full n-bit codomain, exactly one output remains unused; it **must** be \`F(z)\`. The complete vector truth table is now known without the final input query. Apply the exact Boolean Möbius transform separately to the \`n\` output bits, check the maximum degree of a nonzero ANF coefficient, and decide \`LowDegree_D\`. This proves the upper bound \`2^n−1\`.

The matching bound applies to **exact deterministic certification** over arbitrary permutations. It does not preclude a *probabilistic* confidence assessment under an explicit source distribution, a degree certificate supplied with an audited source circuit, a special algebraic family with stronger structural promises, or a different guarantee (e.g., inversion of a single observed target under a genuine prior premise).

## Sharper exact bound for **known-coordinate compatible permutations**

Restrict the competing oracles to **known-coordinate triangular/compatible permutations** \`P_i(x)=x_i⊕h_i(x_0,...,x_{i-1})\` using the caller's given ascending bit order, with no unknown affine input/output wrapper. The exact deterministic worst-case query count now tightens to

\[
Q_\mathrm{compatible}(n,D)=2^{n-1}\qquad (n\ge 3,\; 1\le D\le n-2).
\]

**Lower bound:** Run any deterministic adaptive oracle procedure on the identity using fewer than \`2^(n−1)\` distinct queries. The pigeonhole principle guarantees at least one unseen lower-\`(n−1)\`-bit prefix \`p\`, since each query covers only one such prefix. Now define \`G_p(x)=x⊕2^{n-1}\` if \`x mod 2^{n-1}=p\`, and \`G_p(x)=x\` otherwise. It swaps precisely the two inputs sharing prefix \`p\` and differing in the highest bit; all lower output coordinates remain identical and the highest output coordinate is \`x_(n−1)⊕δ_p(x_0,...,x_(n−2))\`. This is a genuine **known-coordinate compatible permutation**, degree **exactly \`n−1\`**, and its adaptive transcript is identical to identity's because the observer never queried the gated prefix. Hence no exact \`LowDegree_D\` decision is possible with fewer queries.

**Matching upper bound:** Query **one** input \`x=p\` with highest input bit zero for each \`p=0,...,2^{n−1}−1\`. For any compatible permutation the sibling output is always \`P(p⊕2^{n−1})=P(p)⊕2^{n−1}\`: lower outputs depend only on the lower prefix, while injectivity forces the top output bit to toggle. Thus these \`2^{n−1}\` queries reconstruct the complete truth table, and exact Möbius inversion decides the degree. For n32 and D≤30 this is **2,147,483,648** chosen queries. It remains enormously larger than the **529** used for conditional quadratic interpolation.

**Explicit scope:** The known-coordinate proof assumes the top-bit direction is known to the observer and the function is compatible in that **published** input/output bit ordering. With secret input/output affine wrappers, both the input direction and output difference are unknown, and the upper-bound reconstruction strategy \`P(p⊕top)=P(p)⊕top\` is **not directly available** from the public coordinate axes. The \`2^(n−1)\` number therefore is **not** asserted to be an exact threshold for the two-sided affine-sandwich class. The larger arbitrary-permutation lower bound \`2^n−1\` is likewise **not** a valid lower bound for a more restricted promised triangular class.

The corresponding [\`compatibleDegreeWitness\`](../sims/permutation-degree-certification-lower-bound.js) and [\`reconstructKnownCompatiblePermutation\`](../sims/permutation-degree-certification-lower-bound.js) implement the lower- and upper-bound constructions. The focused [Ubuntu/Windows run 45115010141](https://github.com/FlareZ123/obfs/actions/runs/45115010141) at \`9f1ac5f0b4c13b8645adb315efa493b737b3ca2c\` **passed** all tests and strict JSDoc. The reproducible test covers 32 adaptive reference/gate couplings at widths 3..10, exhaustively reconstructs **all 128** known-compatible width-3 permutations using **four** forward queries each, and reconstructs randomized highest-bit gates at widths3..10.

The separate [source-pinned two-platform focused run 45114940544](https://github.com/FlareZ123/obfs/actions/runs/45114940544) at commit `6d83dc598369281d585b79be416315cbc89432bf` passed the arbitrary-permutation witness and strict JSDoc on Ubuntu and Windows.

A separate \`2^n−1\` output oracle reconstruction check proves the missing codomain output is uniquely determined. This is a finite-width computational **illustration** of the mathematical proof; the claimed general bound relies on the exact algebraic derivation, not on extrapolating ten-bit samples.

The previously committed [\`sims/rare-prefix-mask-certificate-lower-bound.js\`](../sims/rare-prefix-mask-certificate-lower-bound.js) focuses on indistinguishable *rare-prefix compatible/triangular permutations* under bounded adaptive audits. That result is stronger in a different dimension (retaining the compatible grammar) and includes an actual sparse gate, but does not claim the general sharp \`2^n−1\` bound for **all permutations**. This proof intentionally works over the larger class of *arbitrary* bijections, including output transpositions that need not preserve triangular compatibility. It cannot be quoted as a sharp lower bound when a verifier is additionally guaranteed compatible structure.

## Obfuscation relevance and honesty boundary

A trusted build pipeline may **prove or audit the degree upper bound from the original source code**, but an attacker looking only at 529 legitimate forward RPC results cannot distinguish a truly quadratic source from one which behaves quadratically on those inputs and hides rare high-degree swaps elsewhere. Thus the 529-query clone and model-to-inverse algorithms are conditional on degree and triangular-affine structural promises; they are not *universally authenticated source certificates*, cannot prove server-source equality after shutdown, and cannot underpin an unconditional obfuscation-security or deobfuscation claim. In the SCO mode a legitimately authenticated client can query only what authorization allows; if the server restricts rate, input domain, or principal activity, the oracle availability assumptions can change. In COO and SNO the adversary's ownership of browser/Node runtime makes stronger source/trace attacks possible but does not by itself establish the degree promise.
