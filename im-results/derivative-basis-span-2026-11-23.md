# Exact input-basis generation of global derivative-defect spans

**Status:** Intermediate mathematical note and reproducible finite verification. Independent reviewer Agent 17, 23 November 2026. This is an attacker-side algorithmic simplification, not a positive obfuscation-security result or a production compiler change.

## General theorem

Let \(F:V\to W\) be any function between finite-dimensional vector spaces over GF(2), with no continuity, polynomial, injectivity or permutation assumption. Define

\[
Z_F(x,v)=F(x+v)+F(x)+F(v)+F(0),
\]

where additions are XOR. For any linear subspace \(U\subseteq V\) and any generating basis \((u_1,\dots,u_k)\), **the global defect span along U is already generated by its basis directions**:

\[
\operatorname{span}\{Z_F(x,v):x\in V,\ v\in U\}
=
\operatorname{span}\{Z_F(x,u_j):x\in V,\ 1\le j\le k\}.
\]

The identity

\[
Z_F(x,u+v)=Z_F(x,u)+Z_F(x+u,v)+Z_F(u,v)
\]

holds by expanding and cancelling the four function-value terms. On the right, the last two terms have the same direction v, including a permitted shifted basepoint. Induction on a basis representation of v puts every left-side defect in the span of basis-direction defects. Reverse inclusion is immediate because each basis direction lies in U. This theorem holds **even for arbitrary truth-table functions**, provided the basepoint x ranges over the entire input vector space. Restricting x to a subspace without accounting for its shifts changes that premise.

For source-function changes, a scalar mask m has globally constant derivative on U exactly when it annihilates this entire span. Consequently the basis-direction span and the full-direction span give exactly the same admissible mask space and the same greedy CEGAR choices. This is an algebraic equality; not an empirical approximate-sampling statement.

## Bounded-degree interpolation corollary

For a map F promised to have Boolean ANF degree at most d, each function (x\mapsto Z_F(x,u_j)) has zero constant and degree at most d-1 in x. Its **complete** set of nonconstant ANF coefficients, for the k basis directions only, generates the full defect span. The coefficient-vector count before zero elimination is

\[
k\sum_{r=1}^{d-1}\binom{n}{r}.
\]

For n=32 and d=3 (the exact cubic CEGAR implementation in `sims/exact-cubic-compatible-cegar.js`), the basis-only source has 528 contractions and 278,784 coefficient-vector entries across all 32 levels, instead of the implementation's reported 5,984 contractions and 453,376 coefficient-vector entries. The current explicit pair-direction `contract(u_p XOR u_q)` calls are mathematically redundant after the first- and second-order x-coefficients have been generated for each basis direction. This reduces the *nominal contraction count* 11.33-fold; **no real CPU-speed improvement has been measured** and model/interpolation/linear-algebra runtime may dominate.

For d=4, the same exact reduction applies using all nonconstant x-ANF coefficients through degree 3; obtaining their coefficients still requires a degree-four source promise and the ordinary 41,449 low-weight queries at n=32. This note does not introduce a practical degree-four implementation or make any universal unknown-source degree promise.

## Finite independent verification

The dependency-free `sims/derivative-basis-span.js` and `test/derivative-basis-span.test.js` implement separate GF(2) rank computations of (i) all x and all v in U, and (ii) all x but only generator directions in U. The fixed test input is:

- All 256 maps from 2 input bits to 2 output bits, across ten valid empty/one/two-generator choices: 2,560 equality checks.
- 1,500 reproducibly seeded random maps from 2–6 input bits into 3–7 output bits, with non-coordinate independent input bases and random subspace dimensions. Seed: `0x71d1ae57`.

Every rank comparison passed in the developer's local Node runtime. The test should also run in the repository's ordinary Node test suite to produce a future source-pinned CI receipt. These finite tests are implementation checks, not the reason the theorem holds.

## Reproduction

```sh
node sims/derivative-basis-span.js
node --test test/derivative-basis-span.test.js
```

Expected simulation output: `{"exhaustiveWidthTwoCases":2560,"randomCases":1500,"seed":1909567063}`.

The existing exact cubic implementation has not been changed; a source-pinned red/green derivative-mask equivalence test and workload-specific timing should precede any integration. The previous exact cubic report `im-results/exact-cubic-compatible-cegar-2026-11-23.md` correctly recorded the older 5,984 contraction count for its unchanged code. It should not be retrospectively described as already optimized.

This result establishes no source confidentiality, unauthorized-execution resistance or universal 2.5x runtime guarantee. The primary release decision remains **RELEASE-BLOCKED**.
