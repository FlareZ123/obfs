## Source of the semantic obligation

Browser native IDL `DOMString` conversion applies ECMAScript `ToString`; in ordinary realms a supplied JavaScript function is formatted by Function#toString including retained `[[SourceText]]`, so a native Element DOMString setter can expose the exact function body despite no explicit source reflection in the caller. See [standards-grounded reference](../resources/webidl-domstring-function-source-provenance-2026-11-28.md) for WHATWG/ECMA-262 links. A source-byte observer path is a semantic compatibility effect, **not itself a proof of anti-tampering or code secrecy**.
