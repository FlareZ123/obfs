# Exact degree-four cloning and basis-only greedy inversion

**Status:** Intermediate research implementation and conditional mathematical result. Not an obfuscator backend or an academically promoted security theorem.

**Owner:** Agent 17, 23 November 2026.

**Code:** `sims/exact-quartic-compatible-cegar.js`, `test/exact-quartic-compatible-cegar.test.js`.

## Promise and attacker knowledge

The defender's forward function is a 32-bit bijective, two-sided-affine-wrapped triangular Boolean map of algebraic degree at most four. The attacker has chosen-input access to that forward function and is assumed to know the **structural family and degree bound**, not its private masks, affine offsets, gate coefficients, or source bytes.

A degree-at-most-four truth function can be interpolated exactly from the low-weight input mask responses:

`Q(32,4) = C(32,0) + C(32,1) + C(32,2) + C(32,3) + C(32,4) = 41,449`.

The existing `learnBoundedDegreeOracle` performs the 41,449 queries and Boolean Moebius inversion. Everything that follows is **offline**, using this coefficient table. The data does **not** certify the source's degree bound; a five-input AND gate placed into the 31st triangular output bit agrees with identity on all masks of Hamming weight <=4, but not on input 31.

## Exact global defect span from 528 direction contractions

For any function on a vector space over GF(2), define its difference defect:

`Z(x,v) = F(x+v) + F(x) + F(v) + F(0)` (all plus signs are XOR).

For any input subspace U, the entire output span of `Z(x,v)` for arbitrary x and v in U is generated by the directions of **any basis of U**. The elementary identity

`Z(x,u+v) = Z(x,u) + Z(x+u,v) + Z(u,v)`

proves this by induction; no polynomial-degree bound is needed for the basis-direction lemma itself. See the separate review and finite verifier in `im-results/derivative-basis-span-2026-11-23.md`.

For a source of degree <=4, fix one direction v. The polynomial `x -> Z(x,v)` has no constant term and degree <=3. Its 5,488 nonconstant ANF coefficient slots exactly span its values. Thus the complete global certificate on a k-dimensional U uses **k** direction contractions, each yielding at most 5,488 vector coefficients. A 32-stage greedy peel contracts

`32 + 31 + ... + 1 = 528`

directions and considers at most `528 * 5488 = 2,897,664` coefficient-vector slots before streaming them into a rank-32 GF(2) row span.

## Direct coefficient contractor

For every ANF monomial M (of weight 2, 3 or 4), and for each nonempty proper subset S of M, the monomial contributes to the coefficient of `x_S` in `Z(x,v)` the vector value `c_M` if **all bits of M minus S are set in v**. The terms with S empty or S=M cancel, exactly as the defect definition requires.

The contractor precompiles these source-independent subset-to-slot relationships from the public reconstructed coefficient table once. Each new direction v then accumulates its own coefficients into a typed array and immediately streams nonzero coefficients to a GF(2) rank-32 pivot accumulator. The implementation does not enumerate the exponential input domain or invoke the private oracle after fitting.

A critical unsigned boundary was identified during local debugging: `(v & requiredMask) === requiredMask` incorrectly rejects required masks whose top bit is set because JavaScript bitwise AND yields a signed Int32. The implemented check normalizes first: `((v & requiredMask) >>> 0) === requiredMask`. The initial unnormalized prototype stalled at a late peel; the corrected one completed the same fixture. This negative is preserved here to avoid similar unsigned-mask regressions.

## Exact greedy triangular inversion

At each current input subspace U with basis, the global defect-annihilator space comprises precisely the output masks whose scalar first derivative is independent of every basepoint along U. For the promised form

`F(x) = a + B P(Ax + b)`, with `P_j(z) = z_j + g_j(z_0,...,z_(j-1))`,

choose the least coordinate j on which AU varies. The output mask `m^T B = e_j^T` yields the nonzero constant derivative `(Ah)_j` for all h in U. Thus a viable mask exists at every nonzero U. The implementation chooses a nonzero restriction to its current output image V, peels both kernels and records an input toggle. Exactly 32 peels invert every target when the degree and triangular-bijection promises hold; the implementation checks the final forward equality.

This is a composition of the existing global-derivative flag theorem with the new exact basis-only defect certificate. It does not establish inversion for arbitrary quartic permutations or arbitrary JavaScript functions.

## Finite reproducible checks

The test fixture independently constructs lower-prefix triangular gates formed from parity-products of degree 2, 3 or 4, adds linear/constant lower-bit terms, and wraps the resulting bijection in invertible xorshift-based linear input and output maps with independent offsets.

The local test exercised four promised sources (one quadratic, one cubic and two quartic), fitted their corresponding 529 / 5,489 / 41,449 low-weight observations, verified the highest-degree source coefficients are nonzero, and for each tested 16 held-out high-weight inputs checked exact clone equality and unique target inversion. **All 64 held-out inversions passed** locally on Node 22.16.0. Each case made exactly 528 coefficient contractions. An independent degree-five sparse gate was correctly identified by the negative control as outside the quartic promise.

Local timing (non-comparative and non-release-grade): each quartic source fitted in approximately 0.14 s and prepared its offline inverter in approximately 2.0 s on the author's container. This is **not** a controlled benchmark, does not measure transport costs, and says nothing about the obfuscator's 2.5x runtime budget.

## Prior-work distinction

This is **not the first known exact degree-four inversion algorithm in this repository**. The pre-existing `sims/bounded-degree-symbolic-affine-inverse.js` already supports degree-two, degree-three and degree-four compatible-triangular target inversion after the same low-weight ANF learning, by **target-specific symbolic restriction of the entire coefficient table**. The `Q(32,4)=41,449` query bound comes from the existing generic bounded-degree learner, not this work.

The distinct candidate here precomputes a global, target-independent derivative flag using the basis-only span identity, then reuses that flag for multiple target values. Whether this improves total compute, peak memory or amortized break-even compared with the established symbolic inverter has **not yet been independently benchmarked**, and neither method provides positive obfuscation security. The proof and tests establish a second, independently structured exact inverter under the same source-family promise.


## Incremental exact-inverse refinement and paired competitor receipt

A subsequent refinement adds `invertFast(target)` alongside the original `invert(target)`. After the exact 528 contraction certificate, it precompiles **32 additional** fixed-direction defect polynomials, one for each selected input-toggle vector. When the greedy output mask indicates a toggle, it updates the maintained model output by the exact identity

`F(x+u) = F(x) + Z(x,u) + F(u) + F(0)`.

The precompiled `Z(x,u)` has at most 5,488 nonconstant x-ANF coefficients (cubic in x), so the fast method need not re-evaluate all 41,449 full-model coefficients for each of the 32 peel decisions. It still checks a final independent full-model evaluation. The returned counters distinguish **528 certificate contractions** from **32 optional incremental-derivative contractions**. The original inverse remains as a comparator.

An independent same-public-model test now compares the globally precomputed flag and both inversion paths with the repository's **existing target-specific symbolic quartic inverse**, rather than implying the degree-four inversion family is new. ## Final input-contract guard (same model, new negative controls)

The final research API rejects non-integer, negative, overflowing and non-finite **target words** in both `invert` and `invertFast`, rather than allowing implicit JavaScript Int32 truncation (the pre-fix identity-model witness mapped `-1` to `0xffffffff` and `4294967297` to `1`). The contractor likewise rejects explicitly malformed unsigned coefficient pairs and monomial masks whose Hamming weight exceeds the declared model degree. Sparse but otherwise valid coefficient tables remain supported. These input checks cannot detect **absent** high-degree terms in a secretly higher-degree source, as the sparse degree-five oracle negative demonstrates.

Both explicit-fail-closed regression families passed Ubuntu and Windows focused CI in [run 45261477252](https://github.com/FlareZ123/obfs/actions/runs/45261477252), immutable `93bf04a4648b25fea696d89f94f20f93c034bf04`.
