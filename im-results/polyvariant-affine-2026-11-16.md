# Polyvariant affine native compiler: generated case partition and adversarial measurements

**Agent 2, 2026-11-16.** Status: reproducible intermediate engineering experiment, opt-in. No academic obfuscation hardness result is claimed.

## Implementation and actual artifacts

The experimental backend [src/affine-native.js](../src/affine-native.js) exports lowerPolyvariantAffine and is integrated into [src/core.js](../src/core.js) and COO/SNO CLI selection. The [before-and-after](../examples/polyvariant-affine/README.md) consists of the complete [original](../examples/polyvariant-affine/original.cjs) and compiler-generated [obfuscated](../examples/polyvariant-affine/obfuscated.cjs) files, with an exact-output [regeneration verifier](../examples/polyvariant-affine/build.js).

The bounded accepted grammar is a one-parameter function containing a single integer-normalized left-associative addition/subtraction chain of 8–64 literal-byte steps. A source proof refuses unsupported operator trees, known source observation, dynamic eval/with, async/generator functions and duplicate target declarations. A single runtime ToInt32 of the original input precedes the switch; every input maps to one of 2, 4 or 8 disjoint integer congruence classes. The selected class reconstructs its own exact signed-int input, then executes a per-class independently seeded affine accumulator through native arithmetic. A completely general plaintext fallback was removed. Generated case count increases linearly with the requested class count. Module and CommonJS function declarations are supported, scripts are deliberately excluded from the integrated experimental mode.

The seed and all case bodies are public. No claim is made that the transformation's input-dispatch arithmetic is hard to invert.

## Pinned cross-platform evaluation

[Focused workflow 43801588768](https://github.com/FlareZ123/obfs/actions/runs/43801588768), exact source SHA **27a62b910d467d6fca68bc0d4b4ac2da74b8b854**, completed successfully on Ubuntu and Windows with Node 22.23.4. It passed six targeted Node tests (including native multi-seed 2/4/8-path differential inputs, non-number conversion effects and exceptions, exported ESM, CLI and programmatic integration, explicit decline/overlap), the full project strict JSDoc typecheck, deterministic checked-in sample reproduction, a source-only reconstruction attack, and three dense/mixed benchmarks. The sample used the same seed and generated bytes on both OS after normalizing checkout line endings.

Protected-runtime method: each ratio divides the transformed 250,000-call median of seven warm timing trials by the native baseline median under the same workload. Three deterministic warmups precede timing. Integer values vary under a repeated LCG; checksum equality is asserted. The mixed workload runs eight extra local native arithmetic steps after each protected call. These are isolated tight-loop wall-clock measurements on shared CI runners, with no full-application or network latency accounting.

The Windows two-variant 2.188× observation, and seed-dependent JIT behavior, caution against treating this as a universal bound. Startup, JIT compilation, cold parse and memory costs are not amortized by the COO budget and have not yet been measured here; actual application policies must profile end-to-end. The mode should remain experimental.

## Independent offline adversarial attack

The attacker [sims/polyvariant-affine-static-recover.js](../sims/polyvariant-affine-static-recover.js) imports Acorn to parse only distributed obfuscated source. It recognizes the generated function normalization and switch, interprets the native integer AST for **two inputs from each declared congruence class**, and deduces the additive mapping when all classes agree. It does not load, import or execute the distributed program. The checked-in two-class sample is reconstructed as signed-Int32 normalization plus an addition of **262**, despite two differently masked case bodies. The six-test suite additionally generates 2/4/8 variants and verifies 512 held-out integer values for each recovery, with a test of a side-effectful numeric-coercion object. This provides a deliberately negative security control: full-control source access defeats this candidate's abstract syntax hiding on the tested grammar.

### Independent dimensions

- **Static reconstruction:** defeated on every tested 2/4/8 variant; all case-dependent constants and inverses are included in delivered code.
- **Dynamic extraction/instrumentation:** the full-control runtime can instrument the switch and all native cases. No empirical resistance claim was established.
- **Tampering/host lock:** no trusted external verifier or unforgeable environment lock is introduced.
- **Compatibility:** bounded function grammar only; tested native value, errors and observable ToPrimitive calls. Source introspection is a known exclusion, and complete arbitrary-program equivalence is unproved.
- **Performance:** hot sample passes the 2.5× threshold; compile/startup and unseen applications remain unevaluated.

The mainline default policy is unchanged. The result is a concrete additional low-dispatch structure transform and an explicit evidence-backed counterexample to claims of full-control confidentiality.
