# Proposal: effect-aware provenance for native-reflection closed-world proofs

**Agent 6, 16 November 2026. Status: proposed research design; not an implemented proof system.** The three merged Agent 6 repairs are finite syntactic improvements. This document describes how to test and replace that growing family of patterns without treating their observed green tests as complete semantic soundness.

## Evidence motivating a reusable abstraction

- [PR #28](https://github.com/FlareZ123/obfs/pull/28): two **actual** cross-platform semantic failures arose when an entry extracted the mutable ambient `Reflect` capability through a computed object-pattern **declaration** and wrote `.ownKeys`. An unrelated exported object field was renamed even though a fixed preloader's callback dynamically imported and enumerated it. [Red 43872277758](https://github.com/FlareZ123/obfs/actions/runs/43872277758), [green 43876531480](https://github.com/FlareZ123/obfs/actions/runs/43876531480).
- [PR #30](https://github.com/FlareZ123/obfs/pull/30): **three** more actual cross-platform semantic mismatches appeared when the identical capability was acquired through an object-pattern **assignment**, possibly forwarded or obtained from a local root alias. The original alias graph already followed ordinary assignments but only the declaration-form destructuring pattern populated the host capability set. [Red 43879639756](https://github.com/FlareZ123/obfs/actions/runs/43879639756), [green 43879794268](https://github.com/FlareZ123/obfs/actions/runs/43879794268).
- [PR #29](https://github.com/FlareZ123/obfs/pull/29), adapting [Agent43's hypothesis](agent43-null-prototype-record-proof-hypothesis.md), retained positive protected work with exact `{__proto__:null}` local record syntax. The measured distinct six-module app with a literal missing-key call achieved **2/2 private owner-field rewrites**. Under an injected host `Object.prototype.noSuchField=Function`, the missing key stays undefined. [Full Chromium and paired runtime green 43878535283](https://github.com/FlareZ123/obfs/actions/runs/43878535283). The frozen source-observing app remains **0/2**; its public-only offline clone succeeds. All three merged source revisions coexist and passed [integrated main run 43880636281](https://github.com/FlareZ123/obfs/actions/runs/43880636281).

These observations show concrete false acceptance when the alias provenance engine misses a transfer form, and a concrete safely accepted special case where prototype inheritance can be ruled out. Neither observation proves that a general strong obfuscator has been built.

## Proposed finite, testable semantic contract

**Scope:** ordinary/default Node ESM loader or browser ESM URLs whose complete declared source set is known. Assume a fixed, explicit host prelude and that source-visible effects from all declared modules are modeled. Do not claim soundness for arbitrary injected scripts, ServiceWorker realms, dynamic code evaluation, cross-realm loaders or attacker-controlled runtime mutation. A compiler feature may operate more conservatively with a wider contract.

**Identity:** track lexical bindings with scope-qualified IDs and module identities, not spelling-only sets. Use binding versions or may-analysis on mutation to prevent a local shadow from being mistaken for a global intrinsic.

**Abstract values:** represent sets of possible origins among `LocalRecord(id, prototypeShape)`, `Intrinsic(Reflect)`, `Intrinsic(Object)`, `HostRoot`, `HostCallable`, `Primitive(type)`, `External` and `Unknown`. Treat unknown computed property names, unknown call results and arbitrary Proxy access as `Unknown` until a stronger proof discharges them. Require the join to overapproximate every possible runtime value.

**Required transfers:** normalize `VariableDeclarator`, `AssignmentExpression`, function parameter binding, ObjectPattern/ArrayPattern, return values, call arguments, direct/namespace ESM imports and exports, object/array containers, aliases, captured closures and reads/writes. For example, `({['Ref'+'lect']:cap}=globalThis)` must yield `Intrinsic(Reflect)` at the `cap` binding. `function replace({['Ref'+'lect']:cap}){...};replace(globalThis)` is a plausible next **unverified hypothesis** for the current implementation, and must be measured before asserting a new defect. Arbitrary unknown receivers must refuse only where their effects can reach the owner or native-reflection assumptions that a proof depends on.

**Effects:** propagate `MayRead/RevealPropertySpelling(record)`, `MayMutateReflectionMethod`, `MayImportUnlistedModule`, `MayObserveFunctionSource`, `MayInvokeOpaqueHost` and `MayEscape(record)` through calls until a fixed point. A source-visible assignment whose receiver may be the real `Reflect` and whose property name may equal `ownKeys` must invalidate any proof depending on that method's native behavior, even if the spelling `Reflect` never appears in that assignment. A host-callable return should not automatically be assumed loader inert. Preserve narrower and cheaper local proof routes where no such effect is reachable.

**Record shape:** recognize the precise standardized object-literal prototype setter `__proto__:null` (or quoted equivalent), distinguishing it from computed own fields. Only a local unescaped record with primitive own literal values, a fully proven callsite set and no relevant mutation effects can make missing-key reads definitely undefined. Ordinary records must account for arbitrary inherited keys and an injected `Function` on `Object.prototype`.

## Acceptance gates and practical output

For each addition, require all of: a pinned original/emitted **real Node and browser** behavioral comparison where relevant; a **pre-fix counterexample** for bug claims; one unchanged benign **positive transformation** demonstrating meaningful protected work; full named/aliased/missing-key negative coverage; strict JSDoc with Windows compatibility; real repeated runtime performance; and, separately, a public-code-only attack measuring attacker reconstruction or cloning.

A useful deliverable would be a module-level effect-summary API (e.g. a map from lexical binding IDs to origins and function IDs to effects) and a provenance query that the cross-file property pass can call, with cross-file import/return/call edges. First compare its decisions against the known 2+3 red cases and the one-owner-key / two-owner-key green cases. Prefer reportable false-positive/false-negative rates and protected-work fractions on an unchanged frozen application over adding more scattered syntactic exceptions.

## Open questions

The true boundary of `closedWorld` remains an explicit contract decision. A complete list of files still does not close a hostile host's dynamic imports or `Function` construction. Research should distinguish source-visible language effects, fixed host capabilities and completely attacker-owned runtime instrumentation. For COO/SNO complete-control threat models, source transforms alone cannot ensure general unextractability. SCO may withhold server-private computation, yet unlimited authorized online query forwarding remains a separate attack. A genuinely stronger obfuscator needs independent attacker-cost evidence, not solely transformations that pass differential tests.
