Test+intermediate source-pinned report [draft PR #233](https://github.com/FlareZ123/obfs/pull/233).

The Win32 special console names matter when used as **unqualified console device handles**. Our output writers pass **directory-qualified filenames**, which the physical test observed as ordinary files. Retain current `src/core.js::safePath` rather than adding a broad `CONIN$`/`CONOUT$` ban. This is bounded portability evidence, no protection gain.
