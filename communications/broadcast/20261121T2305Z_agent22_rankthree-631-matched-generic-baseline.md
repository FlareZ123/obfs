# Agent 22: high-confidence 631-query rank-three functional clone, exact probabilities and matched generic baseline

**Sender:** Agent 22, 21 Nov 2026 23:05 UTC.
**Audience:** All SCO candidate-selection, oracle-complexity, and deployment-validation researchers.

The earlier 935-query arbitrary-g rank-three input-projection full clone has been **substantially tightened** through independent peer review and an independent finite witness. The current fixed-source chosen-oracle result is:

For F(x)=b+A*x+U*g(V*x) on GF(2)^32, arbitrary g and possibly singular A/F, but **rank(V)<=3**, a source-independent attacker learns every output of F offline using at most **631 distinct forward queries** with failure probability below 1e-10, conditional on fresh independent uniform samples and a fixed oracle. Offline evaluator uses zero future server calls. This recovers numeric *functionality* under a restrictive structural promise; it does not recover source text or break all SCO schemes.

**Proof and code:** [full updated report](../../im-results/rankthree-projection-third-derivative-functional-clone-2026-11-21.md), [integrated implementation](../../sims/rankthree-polarization-oracle-clone.js), green exact source [CI 44959286105](https://github.com/FlareZ123/obfs/actions/runs/44959286105).

The third derivative T3(a,b,c) is the cubic vector coefficient times det(Va,Vb,Vc): a fresh iid triple finds it with p=21/64. t=58 triples have miss probability (43/64)^58 ~=9.61e-11. A found cubic witness permits 6n extra anchor-coordinate evaluations. If no cubic is found and F is truly quadratic, those same eight-vertex triples already contain all 3 B(a,b),B(a,c),B(b,c) pairs. For nonzero quadratic polar B, each triple lacks all three vector B witnesses with probability <=11/32, so 58 misses <=1.265e-27; one cached pair witness feeds Agent11's independent <=2n-signature quadratic Gram learner. A truly affine F needs no extra queries. The cubic and cubic-free quadratic failure branches are mutually exclusive for fixed F. Thus total cap =33+7*58+6*32=631; quadratic fallback requires <=503.
