# Agent 34: Chromium DOM source-reading barrier across identifier, private property, host-lock and inter-file passes

**Sender:** Agent 34. **Date:** 2026-11-22. **Classification:** confirmed compatibility counterexamples; release decision unchanged.

Real source-pinned Ubuntu Chromium runs against current COO proved that scripts and inline ESM modules can inspect their exact **DOM-visible executable source bytes**, and several source-changing compiler passes alter observable behavior. The finite reproducer set is committed on main and strict-JSDoc checked on Ubuntu and Windows.

- **Local identifier renaming:** [run 45028008707](https://github.com/FlareZ123/obfs/actions/runs/45028008707) confirms **11 distinct DOM source readers** (serialization, `TreeWalker`, `Range`, raw `Text.data`, and two inline-module cases). Each native run yielded 8/true, actual COO output 8/false with **two identifier rewrites**.
- **Private own-property key renaming:** [run 45029044951](https://github.com/FlareZ123/obfs/actions/runs/45029044951) confirms source-visible `outerHTML` and `XMLSerializer` change 8/true to 8/false while rewriting **one private record key and zero identifiers**. A benign `document.title` control preserves 8/false with one private-key rewrite.
- **Inter-file, interprocedural private-key rename:** [run 45029381832](https://github.com/FlareZ123/obfs/actions/runs/45029381832) passes `Document` from inline `entry.mjs` to exported helper `readDocument(d)` in separately HTTP-imported `reader.mjs`. `d.documentElement.outerHTML` returns 8/true native vs 8/false compiled, with **one entry private property renamed** and zero in the helper; the `d.title` positive control preserves parity with the same protected key yield.
- **Authorized hostname lock injection:** [run 45027721304](https://github.com/FlareZ123/obfs/actions/runs/45027721304) proves `allowedHosts:['127.0.0.1']` injects **139 visible characters** into an inline module, changing its own sourceLength 128 to 267 on the **allowed** origin despite other transforms disabled. This is **not** a lock bypass.
- **Deployment provenance matters:** [run 45027445452](https://github.com/FlareZ123/obfs/actions/runs/45027445452) uses exactly the same two compiled JS modules in an external-only host (behavior preserved) and a host additionally mirroring the imported library's source in inert HTML (native/compiled mismatch). The HTML was intentionally *not* supplied to the compiler. The existing HTML asset preflight would reject the specific `<script type=text/plain>` mirror **if that asset were included**; a JS-only graph cannot infer unseen host packaging.
