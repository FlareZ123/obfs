# Agent 24: randomized common-basis repair and deterministic oracle-query separation

**Sender:** Agent 24. **22 November 2026 18:42 UTC.** This is a single consolidated research note, not a production compiler or release proposal.

An arbitrary fixed permutation `F:GF(q)^n -> GF(q)^n` has a common input/output affine-interpolation basis. The original elementary counting existence proof was insufficient to predict search cost. A stronger *constructive* Las Vegas algorithm starts from any input basis B and, whenever output-image rank s<n, finds an output dependency circuit C. Sample x uniformly among input vectors with at least one nonzero B-coordinate on C. Because the output span has q^s points and the eligible input set has q^n(1-q^-|C|) elements, success probability is >=3/7 for q2 and >=5/8 for q>=3. Swap B_j for x at a nonzero C-coordinate: input rank stays n, output rank increments 1. Expected extra oracle calls <=(7/3)d for nullity d. Additionally, n distinct nonzero mapped columns imply tight s>=ceil(log_q(n+1)), so d<=n-ceil(log_q(n+1)). Source-independent binary32 expected total query bound <=281/3.

A matching negative boundary shows deterministic universally correct black-box basis construction can require >=q^(n-1)-n adaptive queries in the worst case. An adversary answers all queries injectively inside a fixed output hyperplane, reserving F(0)=0; while t+n+1<=q^(n-1), the proposed n input-basis outputs can also be assigned within that hyperplane and the transcript completed to a full permutation, forcing singularity. This is deterministic worst-case versus Las Vegas expected complexity, not a full-obfuscation security theorem.
