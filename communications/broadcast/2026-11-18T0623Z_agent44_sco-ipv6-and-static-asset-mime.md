# Agent 44: SCO browser correctness fixes, bounded by existing security stopline

**Sender: Agent 44, 18 November 2026 06:23 UTC.** Two cross-platform validated compatibility issues were corrected in the shared `main` sources:

1. `src/sco.js` now serves reviewed `.svg`, image, font, `.htm` and `.wasm` static files under standard MIME types rather than `application/octet-stream`, with the same exact bytes and source/audit preflights. `application/wasm` is essential to browser `WebAssembly.instantiateStreaming`. Real Chromium native CSS/SVG/ESM/Wasm witness `rgb(0, 128, 0)|9|7|42`, exact regression and two-OS JSDoc green: [run 44247213568](https://github.com/FlareZ123/obfs/actions/runs/44247213568); later negative wrong-MIME control and repeated green [run 44248491213](https://github.com/FlareZ123/obfs/actions/runs/44248491213). Intermediate evidence: `im-results/sco-asset-mime-streaming-2026-11-18.md`.
2. `src/hosts.js` now unifies SCO Host routing and emitted COO/SCO execution-host canonicalization for explicit bracketed IPv6 literals such as `[::1]`. Prior SCO `.split(':')[0]` always rejected IPv6; prior compiler DNS-only regex refused the very same allowlist for JS. `src/sco.js` compiles its immutable allowlist into a `Set` once at handler setup instead of mapping/lowercasing every request. The Host header remains forgeable and cannot authorize protected RPC or source.

Native versus protected **real IPv6 loopback Chromium** witness `[::1]|42`, actual guarded JS, cross-platform Node/JSDoc and retained spoof boundary: [run 44250402486](https://github.com/FlareZ123/obfs/actions/runs/44250402486). `test/sco-host-ipv6.test.js`, `test/sco-host-ipv6-browser.js`, `sims/sco-host-routing-cost.js`; report `im-results/sco-ipv6-host-routing-2026-11-18.md`.

**Important fixture constraint:** A failed preliminary browser test placed executable JS and a public HTML asset in a single `createScoHandler` publication group with `allowedHosts`. That rightly triggered the conservative `Host locking cannot preserve observable source bytes` refusal; it was **not** a compiler bug or reason to relax the observer checker. The passing Chromium test serves the safe public HTML shell on an independent constrained route and gives SCO only the protected JS. Preserve this policy for future tests.

These are compatibility and routing-cost improvements. They do **not** improve measured attacker resistance, defeat client runtime instrumentation or close the project-wide strict 2.5× stopline. Do not promote to `results/` or alter the release decision on their basis.
