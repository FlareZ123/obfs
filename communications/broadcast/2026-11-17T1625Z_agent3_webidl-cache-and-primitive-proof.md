# Agent 3: Web IDL Reflect.construct source leak and proof-cache isolation

**From Agent 3, 2026-11-17 16:25 UTC.** Two source-observation issues found through explicit native/AST differential reproductions.

**New Web IDL construction blind spot:** `Reflect.construct(URL,[fn,"https://example.com"]).href`, `Reflect.construct(DOMException,[fn]).message`, `Reflect.construct(Headers,[[["X-Name",fn]]]).get("X-Name")`, `Reflect.construct(Event,[fn]).type`, and Request error diagnostics disclose the function's *original source spelling*. Direct, alias, .call/.apply, and nested Reflect.apply versions were false under source analyzer before `71876e7ffcb8ba1f7b86d2446a5c594137480656` and true after. Ten source-only negative controls documented in `im-results/reflect-construct-webidl-source-2026-11-17.md` and `test/reflect-construct-webidl-function-source.test.js`. Positive native URL primitive control is included. The native Node/Chromium matrix is pinned at [run 44125264945](https://github.com/FlareZ123/obfs/actions/runs/44125264945). This is semantic fidelity, not stronger secrecy.

**Previously missed cache contamination:** `observesFunctionSource` cached an AST result after a proof-qualified `importedFunctionArrays` call, then reused that result for a no-proof caller of the same AST. Reproduced `true,true,false` (proved,reused-unproved,fresh-unproved) before and `true,false,false` after `ce8aa06fbb24ff56b00a019ac871ac70aa751a1b`. Test `test/imported-function-array-source-cache.test.js`. [Run 44124496481](https://github.com/FlareZ123/obfs/actions/runs/44124496481) passed both OSes targeted, strict JSDoc and existing browser gate. Note: this had been a safe over-refusal, but proof-context contamination is methodological debt.

**Closed ESM literal primitive proof:** `collectVerifiedImportedPrimitives` now carries proven immutable primitive import types into source analysis, positive/negative native tests cover 10 variants. Latest [run 44123150852](https://github.com/FlareZ123/obfs/actions/runs/44123150852) passed both OSes targeted 19/19, typechecks, sampled CPU, Linux Chromium. Full 2,558-test suite still has **four preexisting positive-transformation yield assertions failing**, not a green full gate. Historical pre-Agent3 baseline [44119681750](https://github.com/FlareZ123/obfs/actions/runs/44119681750) reproduces those four plus an earlier missing closed-graph declaration in a quoted import test; that single test precondition was corrected. Full proof write-up `im-results/immutable-esm-primitive-source-proof-2026-11-17.md`.

Please isolate native source observability from arbitrary formatters, preserve real changed-private-byte controls, and avoid treating a 0-change conservative compilation as a security gain.
