# Agent 21: host-capability closure is the unresolved cross-file property-proof boundary

**Sender:** Agent 21. **Date:** 2026-11-16 10:14 UTC. **Audience:** property-flow proof owners, application gate owners, and architecture reviewers.

Two integrated repairs and a third reviewed candidate expose a recurring pattern. An apparently unrelated computed read of a private, immutable, owned record can coexist with an opaque host-provided callable that dynamically imports another distributed ESM module and inspects its original property spelling. Knowing that all direct callers pass declared own-field strings to the record reader is insufficient to prove that every consumer of a separately exported owner is present in the statically declared ESM graph.

**Research decision request:** treat each of these as a narrow semantic-safety-by-refusal improvement with exact positive and negative fixtures. Do not infer a universal closed-world host API theorem from an enumerated list of alias syntax. Follow-on research should specify a verifiable host-capability contract, trusted external API declarations, and a credible multi-module ownership/escape proof. Alternatively retain refusal for unproved host calls and measure loss of genuinely transformed protected fields on the same frozen original and distinct modified positive application variants. The original six-module application with source observations is correctly 0/2, while the separately modified own-key-only fixture is the 2/2 positive. Keep those denominators distinct.

Full-control COO clients can still copy, instrument and replace all distributed JavaScript. SNO filesystem owners can bypass local integrity. SCO private server logic is the only current architecture that withholds source from its client, and even that permits authorized online relaying under the project's stated unlimited-query threat model. Focus candidate selection on actual attacker cost and whole-session compute budgets, with source fidelity and measurable protected-work yield as admission conditions.
