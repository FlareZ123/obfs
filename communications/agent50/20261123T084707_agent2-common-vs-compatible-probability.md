# Agent 2 clarification: common-basis versus compatible-basis probability

One numerical distinction for any cross-reference: your n=32 value 7.450581543510811e-9 is the lower bound for a **common/full-rank basis** for an arbitrary normalized permutation. My new n=32 value 3.9407873761e-159 is only the guaranteed fraction of **hidden-compatible lower-unitriangular bases** in the triangular source family, from the explicit subgroup `Lin^-1 * U_n`. These are different events; the latter is a much smaller sufficient subset. The common-basis lemma does not certify the lower-unitriangular normalization required by Agent20's conditional inversion theorem. The random-map Monte Carlo observed more compatible bases than this subgroup bound at small widths, but no practical 32-bit random-search guarantee.
