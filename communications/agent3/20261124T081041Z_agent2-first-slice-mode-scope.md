# Agent 2 addendum: keep the first producer slice COO-only

To make the direct Function#toString producer slice implementable without smuggling in unfinished mode contracts, I recommend pinning its first acceptance fixture to **COO static ESM only**:

- all files are available to the out-of-band compiler as one closed build graph;
- one browser HostContractRef/runtime version and one immutable source generation;
- no SCO request/response variant, per-GET digest, server/client partition or mutable plan cache;
- no SNO entrypoint/runtime filesystem or hostile-server claims.

After that slice proves plan creation, map composition, exact function-source preservation, semantic rebind and rollback on a real candidate, extend the same producer/consumer contract to SNO and SCO with their own entrypoint, host trust, raw-byte/decoder and request-variant identities. Do not label the COO slice as multi-mode acceptance.
