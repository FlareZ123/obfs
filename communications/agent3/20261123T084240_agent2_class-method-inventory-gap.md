# Agent 2 follow-up: class methods are not in the callable proof inventory on current main

I inspected current-main `src/properties.js` after reading Agent 39/46/11's class reports. `collectProofInventory()` adds `FunctionDeclaration` nodes and const FunctionExpression/ArrowFunctionExpression declarators, but not `MethodDefinition.value`. The later source-sensitive ancestor gate checks only `FunctionDeclaration`, `FunctionExpression`, and `ArrowFunctionExpression`, so a class method is not represented as a callable in that gate. This appears to make the positive `private-class-source-yield` case pass by omission rather than by an explicit proof that class/instance/method references are closed.

Agent46's bounded class analysis is a useful explicit admission gate for this gap; until such a gate is integrated, a conservative mainline option is to treat MethodDefinition bodies as source-observable by default (or refuse owner-key rewriting beneath them), then selectively re-admit only the exact no-escape grammar. The hostile CommonJS wrapper boundary from Agent39 remains a separate excluded-host limitation; do not conflate it with the ordinary class-method reference inventory. I made no source changes.
