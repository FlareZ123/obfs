## First implementable slice: source-local binding IDs

Implement `resolveLexicalReferences(ast, sourceType)` as a new **read-only** Acorn AST pass returning `Map<AstNode, BindingResolution>` for each *reference* identifier and `Map<AstNode, BindingId>` for declaration identifiers. A BindingId is a unique in-pass integer plus declaration-node identity; it is never based solely on a spelling. A reference decision is `{kind:'local',bindingId}`, `{kind:'free-host-candidate',name}`, or `{kind:'unknown',reason}`. This is a lexical resolver, so free-host-candidate is **not** a proof that the runtime's global object has native methods. Unknown must veto only a dependent proof, not silently mean “native.”

Build scope nodes before resolving references; predeclare to handle hoisting/TDZ, never infer reachability from textual order. Program scopes depend on source type:
* ESM module: top-level import/var/let/const/class/function declarations are module locals.
* CommonJS: top-level declarations are wrapper-local; special wrapper names require an explicit synthetic binding if needed. Bare `window` can be a host candidate, but `module.exports` and `require` cannot be treated as free browser globals.
* Classic script: top-level `var` and function declarations alias the global environment; conservatively return Unknown for host-name conflicts (`var window`, function declarations), rather than marking them as module locals. Top-level lexical declarations remain local.

Scopes/decls to admit initially: Program, functions (body scope plus parameter scope), arrow functions, block and switch lexical scopes, catch parameter scope, for/for-in/for-of lexical scopes, class expression/declaration self-name scope, named function-expression self-name scope, imports and nested Array/Object/Rest/AssignmentPattern declarations. Hoist `var` to nearest function or Program; lexical `let`/`const` and class to nearest block-like scope; function declaration to its correct containing function/block under strict/module rules. ES sloppy Annex B block-function behavior is nontrivial: classify references affected by Annex B as Unknown rather than declaring a false local proof. Resolve `Identifier` by syntactic role, separately from AST traversal, to distinguish labels, noncomputed property names, shorthand property values, binding patterns, assignments and export specifiers.

For each reference, search the lexical scope chain from the reference *position*, including declarations after that position (TDZ is still local). If multiple incompatible declarations/redeclarations or an unsupported AST form could affect resolution, return Unknown. Do not use `collectBindings(ast).has(name)` as a global veto: a shadow in a sibling function must not hide an unshadowed host-root reference.

Dynamic-scope overlay: mark the body scope of a potentially direct `eval(...)` (where eval is not proven shadowed) and every closure lexically nested under it as Unknown for any free/global candidate or binding that eval could affect. Do **not** taint a sibling of an eval-containing function. For `with`, mark all identifier resolutions inside its body Unknown unless the receiver-independent binding proof is established; fail closed on a computed source-observer receiver. Handle shadowed `eval` differently from proven direct global eval, but an uncertain alias remains Unknown. A simple first cut may conservatively refuse whole affected *function* scope and still be useful.

## Source-preservation plan, not a boolean

Make the resolver produce a source/closure dependency proof consumed by *all* transformation backends. Distinguish `ExactSource`, `SourceBytes`, `FramePosition`, `CallableMetadata`, and `UnknownHostEffect`. For a proven source-visible callable, protect its complete original UTF-16 source interval `[start,end)`, **plus** declarations and references of lexical bindings used in that callable's closure where renaming would create an unresolved reference. This closure dependency may extend *outside* the callable's source interval. Class methods, accessors, constructed functions, inferred names and error spellings require their own effect-specific review. An unknown observed callable must not be guessed from identifier spelling.

Use an edit planning API `applyProtectedEdits(source, proposedEdits, proof)` that either accepts a whole pass or rejects unsafe **edits**, with a conservative fallback to declining the transform. For every edit, prove no intersection with protected intervals; for `FramePosition` effects enforce stable prefix UTF-16 line/column coordinates and independently test stack path/byte effects. An insert before a protected function must not be mistaken for harmless when its location is observed. `applyEdits` still enforces non-overlap and in-range constraints.

**Pipeline identity:** do not carry raw Acorn node identities through `core.js`'s multiple `parse(code,sourceType)` reparses. Freeze the observed native callable source fragments in a pre-transform manifest with file, semantic role and source hash; after **every** backend (VM, native/wasm, property, identifier, string, host guard), reparse fresh, recompute reference IDs/plan, and verify that every originally observed callable still has an unambiguous mapped counterpart and byte-identical source fragment. If an edit shifts spans, record a UTF-16 source-to-output range map or reject ambiguous mappings. New emitted helper code and source-observer effects need a fresh proof. Until a stage supports this contract, keep its present broad veto. An apparent source match based on reused names is insufficient when two functions have the same spelling.
