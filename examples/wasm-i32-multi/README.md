# Experimental multi-parameter typed WebAssembly lowering

This is an **actual compiler-produced before/after CommonJS pair**, generated by the opt-in `lowerWasmI32Functions` backend with seed `agent38-wasm-multi-sample-v1`. The native `fuse(a,b,c)` function contains three interacting signed-Int32 bitvector inputs. The after-file embeds a diversified 83-byte WebAssembly module with three i32 parameters and one i32 result. The original CommonJS function name and call signature remain available to its callers.

Run `node examples/wasm-i32-multi/build.cjs` from the repository root to assert exact generated byte equality and exercise 12,000 typed differential cases. The script also constructs a new WebAssembly instance **only from the public emitted byte array** and clones every tested result. Thus the experiment establishes additional supported source grammar and compatibility, with *no demonstrated resistance to seedless binary extraction, hostile-runtime instrumentation, source disassembly or unauthorized execution*. An instrumented runtime can replace the exported function.

The backend now admits one through four **distinct plain identifier** parameters. Every call must pass primitive signed-Int32 Numbers for every parameter; the compiler does not prove types from arbitrary JavaScript call sites. Unsupported signatures, side-effectful expressions, unsupported operators, source observers and uncertain runtimes are conservatively declined. A top-level unsigned right shift retains its JS unsigned result through `>>>0`. The existing single-parameter compiler output is deliberately unchanged.

The measured warm ratio printed by the reproducible script is a *local workload observation*. Compilation and instantiation costs count for COO, and cold/short-lived workloads can exceed 2.5×, as shown by existing single-input experiments. The multi-parameter backend should remain opt-in and subject to workload profiling. It creates additional structural lifting work for a casual reader, while exposing all computation in distributed bytes.
