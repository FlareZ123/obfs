# Experimental i32 WebAssembly conditional-select lowering

This sample is a real compiler-emitted `before.cjs` / `after.cjs` pair, generated by opt-in `lowerWasmI32Functions` using seed `agent38-wasm-select-sample-v1`. It compiles the pure four-input native bitvector expression:

`return a ? ((b ^ c) & 255) : ((~b) | d);`

into an i32 WebAssembly function using the **`select` opcode (0x1b)**. Every operand is restricted to a primitive signed-Int32 Number expression, so evaluating both possible branches in Wasm does not introduce observable source-level side effects. The source exposes the same four-argument function signature; code outside the allowed pure grammar is conservatively refused. The output is **439 bytes of JS** with **70 embedded Wasm bytes**.

The compiler also supports nested conditional expressions, conditions with bitwise operators, and uniform unsigned-shift returns where both possible arms produce an unsigned Number. A conditional that may return signed on one arm and unsigned on another is declined, because the wasm i32 result cannot preserve the JavaScript representation of both cases through a single wrapper.

Run `node examples/wasm-i32-conditional/build.cjs` to verify the checked-in exact output, test 20,000 native/compiled/reconstructed four-input calls, and print alternating warm-loop measurements. `test/wasm-i32-conditional.test.js` adds 84 seeded trees, 10,752 typed vectors, negative signature/effect cases and COO/SNO behavior.

The separate `sims/wasm-i32-static-recover.js` attacker extracts the published binary and symbolically recovers the **exact conditional expression tree** without the compiler source or seed. The branchless Wasm select therefore increases the admitted control-flow grammar yet provides no demonstrated confidentiality, runtime integrity or authorization. An attacker who can inspect or modify the runtime can still extract or replace the Wasm function. A warm-loop result below 2.5× is not a cold-start or whole-application guarantee; the binary instantiation cost remains chargeable in COO.
