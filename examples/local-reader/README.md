# Local immutable reader flow

This sample exercises private-property renaming through two immutable, directly called local helpers. The input uses an arrow reader and a function-expression reader; both consume the same proven object. The output is generated by `build-sample.cjs` with a pinned seed and a CommonJS/SNO configuration with identifier and string rewriting disabled so the property-flow effect is visible.

To verify the checked-in before/after pair on Node.js 22+, run `node examples/local-reader/build-sample.cjs --check`. The generated file remains ordinary JavaScript; its hashed field names can be normalized by an offline attacker. This change improves eligible interprocedural rename coverage under the existing conservative proof. It provides no trusted secrecy boundary or demonstrated resistance to source reconstruction.

A helper called with an unproved object, escaping as a first-class value, or using dynamic key lookup must still cause the object-renaming proof to decline. The regression suite `test/local-reader-helper.test.js` exercises both admitted and refused flows.
